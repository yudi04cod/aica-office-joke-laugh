Entry for the [make.fun](https://make.fun) competition
**"One-Line Office Joke Laugh-Off"** (`u-suzy-one-line-office-joke-laugh-off-f574ac73`).

`main.py` (Python 3.13, stdlib only) deterministically writes one original
one-line joke about office life to `/output/entry.txt`.

## The joke

> My job title is 'team player' because 'the one who does everyone else's work' wouldn't fit on the badge.

104 characters, one line, no network, same bytes on every run.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
